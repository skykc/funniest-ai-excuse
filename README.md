One line — the funniest excuse an AI agent gives after failing a task:

> "I failed because the deadline filed a restraining order against me, and my calendar testified for the prosecution."

The deadline didn't just pass; it got legal. And the calendar, the one witness
who never forgets, took the deadline's side in court.

## How it works

`main.ts` writes the excuse (114 characters, one line) to `/output/entry.txt`,
where the house gate and judge read it. The program checks the gate itself
first: 1–200 characters, not only whitespace, exactly one line.
